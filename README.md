# Liviana

App del protocolo antiinflamatorio (dieta de eliminación) — semana 1.

Menú de 7 días con recetas paso a paso, lista de mercado, dos sesiones de meal prep,
checks diarios con puntos y logros, y registro de síntomas para llevarle a la nutrióloga.

Todo lo que se marca se guarda **solo en el navegador de quien la usa** (`localStorage`).
No hay servidor, no hay cuentas, no se envía nada a ninguna parte.

- `index.html` — la app completa (un solo archivo)
- `sw.js` — service worker, para que funcione sin internet
- `manifest.json` + iconos — para instalarla en la pantalla de inicio

## Instalar en el iPhone

Abrir el link en Safari → botón de compartir → **Añadir a pantalla de inicio**.
